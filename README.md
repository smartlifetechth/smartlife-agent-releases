# Smart Life Agent

Windows installer for the Smart Life passport scanner agent.
ตัวติดตั้งโปรแกรม Smart Life Agent สำหรับเครื่องสแกนพาสปอร์ต (Windows)

## Download / ดาวน์โหลด

**[SmartLifeAgentSetup.exe (latest)](https://github.com/smartlifetechth/smartlife-agent-releases/releases/latest/download/SmartLifeAgentSetup.exe)**

All versions and SHA-256 checksums: [Releases](https://github.com/smartlifetechth/smartlife-agent-releases/releases)

## Install / วิธีติดตั้ง

1. Download and run `SmartLifeAgentSetup.exe` (Windows 10/11, 64-bit, administrator rights required).
   ดาวน์โหลดแล้วเปิดไฟล์ `SmartLifeAgentSetup.exe` (ต้องใช้สิทธิ์ผู้ดูแลเครื่อง)
2. If Windows shows "Windows protected your PC", click **More info**, then **Run anyway**.
   The installer is not code-signed yet.
   ถ้า Windows ขึ้นข้อความ "Windows protected your PC" ให้กด **More info** แล้วกด **Run anyway**
3. Open the Smart Life Agent icon in the system tray, choose **Settings**, and enter the
   HQ URL, Property API key and License key provided by Smart Life.
   เปิดไอคอน Smart Life Agent ที่มุมขวาล่าง เลือก **Settings** แล้วกรอก HQ URL, Property API key
   และ License key ที่ได้รับจาก Smart Life

The agent does not work without a license key issued by Smart Life.
โปรแกรมใช้งานไม่ได้หากไม่มี License key จาก Smart Life
